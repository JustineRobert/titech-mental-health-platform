# Threat Model

Threat categories: authentication attacks, authorization bypass, tenant escape, IDOR, credential/session theft, injection, XSS/CSRF, unsafe file uploads, data exfiltration, insider threats, API abuse, denial of service, supply-chain attacks and cloud misconfiguration.

Primary mitigations are centralized authentication/authorization, tenant-aware queries, input validation, restrictive clinical permissions, secure cookies, rate limits, private storage, audit logging, security headers, dependency/secret scanning and controlled deployment.

Residual risk requires independent penetration testing and environment review.
